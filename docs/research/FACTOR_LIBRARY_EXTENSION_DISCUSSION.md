# 因子库扩展讨论：现有基础、常用候选与工程边界

记录日期：2026-10-19。

文档状态：讨论记录，不是已批准的实施方案，也不是回测结论。本次仅整理因子描述，不修改策略、权重、股票池或前向纸面交易配置。暂不编入公众号文章序号。

## 一、我们想解决什么问题

当前讨论限定在适合 A 股中低频策略的传统因子，暂不考虑消息、公告情绪和机器学习因子。财务数据仍必须根据公告时间判断是否可用；“不使用公告情绪”不等于忽略财报公告时间。

目的不是凑够多少个因子，而是判断：现有因子之外，是否还缺少有经济含义、能够按历史时点计算、可能提供增量信息的指标。

“与工程不冲突”有两层含义，不能混为一谈：

- 架构兼容：可以沿用股票池、点时点数据、因子面板、评分、融合、回测和交易成本模块。
- 研究有效：加入以后是否提供独立信息，是否改善样本外表现，是否值得承担额外数据和交易成本。

架构兼容不代表研究有效，更不代表可以直接加入实盘。

## 二、现有基础：不能把已有内容误认为缺失

当前六策略配置中，四个综合型策略使用五类、十三个因子名称：

- 估值：PE、现金流收益率。
- 盈利质量：ROE、毛利率、净利率、低资产负债率、现金利润质量。
- 成长：营收增长、利润增长。
- 动量与反转：MOMENTUM、60 日动量、5 日反转。
- 风险：波动率。

价值专项策略还使用盈利收益率、账面市值比和现金流收益率；成长专项策略使用营收增长、利润增长。六策略合计涉及十五个不同配置名称，但不等于十五个相互独立的信息来源，也不代表每只股票每天都有全部有效值。

因此，PB 对应的账面市值比、动量、现金流质量，都不能简单列为“工程里没有”。量比计算、流动性过滤、账户回撤控制也已经存在，但它们不等于换手率因子、流动性评分或个股回撤因子。

另一个需要保留的口径提醒：六策略相关构建路径中，名为 `FREE_CASH_FLOW_YIELD` 的指标使用 `ocfps / close`，即经营现金流每股值与价格之比的代理口径，不是严格扣除资本开支后的自由现金流收益率。通用财务因子函数已支持其他自由现金流字段候选，不能据此说整个工程没有自由现金流支持。未来如更换公式，应单独版本化并重做对照，不能悄悄替换历史定义。

## 三、值得补充的常用候选

### 1. 股息率：公司实际给股东分了多少钱

直观定义：过去一定时期的现金分红与股票市值之比。正式实现时需统一每股或总额口径，以及股份变化的处理方式。

PE、PB 和现金流收益率分别观察盈利、净资产和现金流相对价格是否便宜；股息率观察已经兑现的现金回报。

当前工程尚未形成独立的股息率选股评分。分红入账、复权处理与股息率选股是不同功能。

可以归入估值类。初版可考虑过去已实施现金分红口径，但需要事先明确回看区间、实施日期和可用日期；不得使用未来分红。高股息也可能来自股价大幅下跌，并不自动代表优质或低风险。

### 2. 应计利润率：账面利润中有多少没有变成现金

一个便于理解的候选公式是：

> 应计利润率＝（净利润－经营活动现金流量净额）÷平均总资产。

同样的利润，如果一家主要收到现金，另一家主要表现为应收款增加，盈利质量可能不同。

现有现金利润质量主要使用现金流与利润的比例；这里用资产作为分母，是另一种观察角度。它可能与现有指标重叠，不能预设为独立信号。

可归入盈利质量类，先检验较低应计利润率的研究假设。该公式属于现金流口径代理指标，不应宣称完全复现原始应计利润论文的所有定义。利润与现金流需保持报表范围、报告期间一致，平均资产的取值规则也要固定。

### 3. 总资产增长率：公司扩张了多少

> 总资产增长率＝本期总资产÷上年同期总资产－1。

营收、利润增长描述经营成果；资产增长描述企业扩张和资本投入。这是现有成长因子之外值得补充的信息。

它不是“扩张越快越好”，也不是“扩张一定不好”。应检验资产扩张是否获得相应回报，不能直接照搬利润增长的评分方向。

可以研究为投资扩张类信号，但是否并入现有成长组、如何定义方向，需要预先讨论。不能借此直接向基础股票池增加盈利或扩张过滤。

### 4. Beta：对市场涨跌的敏感程度

直观定义：个股收益与市场收益的协方差，除以市场收益的方差。

- 波动率回答：股票自身波动有多大。
- Beta 回答：市场涨跌时，股票通常跟着变化多少。

当前尚未形成独立的股票 Beta 评分因子。可先用于组合风险分析，再检验是否作为选股信号。

实现前需固定市场基准、回看窗口、最少有效交易日和停牌处理。低 Beta 评分不等于复现完整的 Betting Against Beta 多空及杠杆策略，也不保证市场下跌时不会亏损。

### 5. 换手率：流通筹码交易得有多频繁

> 换手率＝成交股数÷对应口径的流通股数。

现有量比比较成交量与自身历史平均水平；换手率比较成交量与流通股数。二者不是同一个指标。

候选包括一段时间的平均换手率、异常换手率等。不能未经验证就判断高换手或低换手一定更好，也要区分总流通股与自由流通股等分母口径。

数据限制：长历史下载脚本对 `daily_basic` 使用每周最后交易日采样。若研究每日换手率的滚动均值，需要补齐日频字段，或通过可靠的历史流通股数据重建；不能把周频记录当作完整日频数据使用。其他本地数据是否可以补足，需要专项核查。

### 6. Amihud 非流动性：多少成交金额伴随多大价格变化

> 指标＝一段时间内“每日收益率绝对值÷每日成交金额”的平均值。

分母是成交金额，不是成交股数。数值较高意味着相对较少成交金额伴随较大价格变化，但它不是直接测得的订单冲击成本。

基础股票池的流动性门槛负责筛掉明显不适合交易的股票；这个指标可以进一步描述池内差异。两者并不重复。

建议先用于交易成本、容量和风险诊断，再决定是否作为选股因子。研究中的非流动性溢价不代表应该直接偏好更难成交的股票，更不能因此取消基础流动性门槛。

### 7. ROA、ROIC：补充 ROE 的观察盲区

- ROA：资产产生利润的能力。
- ROIC：投入资本产生经营回报的能力。

它们有助于区分高 ROE 是来自经营效率还是较高杠杆，目前尚未形成这两类独立的正式选股评分。

这两项可以作为盈利质量的后续候选，但不必同时加入。特别是 ROIC，税后经营利润、投入资本、平均值口径，以及金融行业适用性，都需要先明确。增加两个名称不等于增加两份独立信息。

## 四、已经有研究计算，但尚未成为日常选股因子的内容

### 1. 总资产毛利率

> 总资产毛利率＝（营业收入－营业成本）÷总资产。

它与当前毛利率不同：毛利率观察销售利润空间，总资产毛利率观察资产创造毛利的效率。

`analysis/quality_asof.py` 已有年度时点版本计算，并处理相应报表有效性；当前实现使用对应报告期总资产。它尚未接入六策略的默认选股配方。

这是“已有研究实现、需要正式接入验证”，不是“从零补一个工程完全没有的因子”。

### 2. 盈利能力的年度改善

同一研究模块已计算总资产毛利率、毛利率、ROE 相对上一年度的变化，使用精确前一年配对。

它回答的是“是否在改善”，与当前水平高低不同。需要关注低基数、异常报告和数据缺失，不能只因变化幅度大就判断质量好。

### 3. 跳过最近一个月的中长期动量

当前已有动量，但“约十二个月回看、跳过最近一个月”的版本与现有窗口不同。

`analysis/signal_asof.py` 已支持回看期和跳过期，可复用计算能力。正式研究仍要明确交易日窗口、复权收益口径和有效历史要求，不能把不同动量窗口都当作独立信息。

## 五、暂定优先级：先讨论六个，而不是一次全部加入

上一轮讨论提出的第一批候选是：

1. 股息率：补充已兑现现金回报。
2. 应计利润率：补充利润兑现与资产尺度的信息。
3. 总资产增长率：补充资本扩张信息。
4. Beta：补充市场风险敏感度。
5. 总资产毛利率：复用已有研究代码，补充资产盈利效率。
6. 跳过最近一个月的中长期动量：复用已有信号工具，比较不同期限的趋势信息。

换手率先核查日频数据；Amihud 先用于风险和交易成本诊断；ROA、ROIC 和盈利改善可作为后续候选。

这只是讨论优先级，不是已经选定六个新因子，更不是已经证明它们能提高收益。

## 六、与现有工程兼容的边界

### 不改基础股票池的职责

基础可交易池继续负责身份、历史长度、数据可用性和流动性等条件。因子研究负责池内比较，不把新增因子的偏好偷偷提前变成股票池过滤。

### 不悄悄改变前向交易配方

当前综合策略采用组内等权、五类预算的结构。即使五类预算不变，某组增加一个因子，也会稀释同组原有因子的权重；缺失数据处理还会影响实际参与评分的因子集合。

因此“接入新因子”不是无影响的数据补充。研究版本应与当前日报配方分开，不能在未验证的情况下修改正在持续记录的前向纸面交易。

### 点时点规则不能省略

财报期末不是数据可用日。计算时必须只读决策时已知的信息，保留更正版本和可用时间；公告当日是否可用，要根据实际决策时点及模块规则明确处理。

还需核查财务口径、单位、股份变化、复权处理、缺失率及行业适用性。已有十多年历史数据，不等于每个新增字段都具有完整可靠的十多年时点历史。

### 增量价值需要同口径比较

后续若实施，应固定股票池、样本期、交易时点、成本和基准，分别检查单因子信息、与已有因子的重复程度，以及加入组合后的实际影响。

IC、分组表现、换手、成本和风险暴露都可以提供证据，但不能只因一次回测收益变高就认定有效。新增因子的窗口、方向和组合方式需要事先明确，最终结论仍需样本外或真正前向数据支持。

## 七、接下来讨论的关键问题

1. 我们最想补的是信息来源、风险识别，还是组合收益？
2. 第一批六个候选是否都需要，哪些与现有指标重复较多？
3. Beta 等风险指标作为选股评分，还是先作为风险监控？
4. 新因子归入现有五类，还是建立独立类别？对应预算如何处理？
5. 使用哪一套冻结的旧策略作为对照，怎样避免加入因子同时改变多项规则？

当前结论：有适合补充的传统因子，但优先补充不同的信息来源，而不是增加名称。先明确公式与数据可用性，再判断是否值得接入默认策略。
